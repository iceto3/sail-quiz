# Курс ветроходство — тест

Интерактивен тест върху учебния материал (КТК и Наредба № 6).

**Сайт:** https://iceto3.github.io/sail-quiz/

Отваря се направо в браузъра — подходящ за лаптоп към проектор и за телефон. Клавиши: `1–4` или `А/Б/В/Г` за отговор, `Enter` / интервал / `→` за напред, `F` за цял екран.
